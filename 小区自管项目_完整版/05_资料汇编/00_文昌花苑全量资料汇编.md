## 二、困境期状况（2025年8月之前）

### 2.1 恶性循环的形成

物业换了一茬又一茬，始终跳不出"服务下滑→业主拒缴→营收亏损→最终撤场"的恶性循环。最后一家物业公司撤走时，物业费收缴率连**10%不到**。[来源：大众日报]

根本原因：**产权混杂+电费代收机制失控**。

- 楼栋产权性质复杂，部分楼栋电费由物业代收，部分直接对接供电局
- 物业以"停电"威胁不缴物业费的居民，形成"电费人质"机制
- 收不上费→服务停摆→更不收，死结越拧越死[来源：今日头条操作细节文]

### 2.2 环境状况（2025年初）

- 道路坑洼，污水四溢
- 垃圾堆成山，夏天走近得捂着鼻子
- 路灯坏了半年没人修
- 化粪池堵塞，污水横流
- 装修师傅评价："还不如我们农村干净"[来源：大众日报 / 央广网]

### 2.3 缴费率变化轨迹（报道隐含）

| 阶段 | 缴费率 | 状态 |
|------|--------|------|
| 正常运营期（有物业时） | 最高约40% | 长期低收缴率 |
| 最后一家物业撤离时 | <10% | 全面弃管 |
| 自管启动初期（2025年8月） | ~10% | 起步艰难 |
| 2026年2月四方共管运转后 | 约40–50% | 逐步回升 |
| 2026年8月 | 突破90% | 稳定运行[来源：大众日报 / 网易深评] |

## 十一、核心判断（写作可用）

1. **这不是"模式胜利"，是"条件胜利"**：特定条件组合（政府隐性投入160万+、退休能人无偿服务、砖混无电梯低维保需求、熟人社会底色）下的个案，不具备普适性。

2. **最值钱的从来不是"一块钱"**，而是那本随时可查的账——打破了"收费难→服务差"的死循环的信任机制。

3. **最大隐患是可持续性**：带头人平均年龄超70岁，低薪用工（接近最低工资）缺乏长期激励，设备大修/安全事故的责任归属尚未明确。

4. **适用边界**：仅适用于超低维保需求的老旧多层小区；高层商品房（含电梯、消防、外墙防水等专业维保）暂不具备自管条件。
