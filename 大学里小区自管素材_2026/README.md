## 核心数据（本会话补抓/核实）

- **湘潭市 2024 财政**（湘潭市统计局公报）：地方一般公共预算收入 **102.41 亿元（-17.4%）**，支出 292.69 亿（+2.4%），民生占 73.8%。
- **东莞二次供水改造对照**（2023 两会委员张敬智建议）：三种资金筹措方案——财政全额出资 / 财政+供水企业 / 财政+供水企业+用户。
- **金鼎物业 2023 考核 = AAA 级**（优秀，92 分及以上，全市 59 家 AAA 之一）。
- **开发商关系链（工商坐实）**：中冶集团（中国一冶，央企）→ 中冶置业武汉（一冶 77.67%）→ 湖南怡富置业（武汉中冶 100% 全资）→ 湘潭金鼎物业（前期物业，住进大学里 1 栋）。

## 写作纪律（事实/判断分轨）

1. **事实句**标注原始数据文件（链接到 `原始数据/` 下的 .txt）。
2. **推断句**标 〔判断〕。
3. **无直接证据**标 〔来源待核〕 并给追问方向——不硬编、不靠推测定罪。
4. 物业费写阶梯价（1.5 / 0.8 / 0.4 元），不笼统写"0.8 元"。
5. 收缴率不作精确数，标"据副局长言论推断"。
6. 考核 AAA ≠ 服务好——相对排名，不覆盖"消防/水改绝对安全"。
